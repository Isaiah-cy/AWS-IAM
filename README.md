# AWS Cloud Security & Identity Management

## 📌 Project Overview

This project demonstrates an **end-to-end AWS Identity and Access Management (IAM) and cloud security implementation** using multiple AWS services in a structured, security-first environment.

The lab simulated a media organisation with four business groups — **Facebook, Instagram, Threads, and IT** — with role-based access controls applied across cloud resources.

## 🎯 Objective

The project was designed to demonstrate practical AWS security and administration skills, including:

* Root account hardening with MFA
* IAM user and group management
* Role-based and resource-level access control
* S3 bucket and EC2 resource provisioning
* Group-specific inline IAM policies
* CloudTrail management event logging
* Automated security alerting with SNS and EventBridge
* Data-at-rest encryption using AWS KMS
* User-level access controls for DynamoDB
* Foundational exposure to Amazon Bedrock

The implementation follows a **least-privilege and security-first approach**, ensuring users receive access based on their assigned business roles.

## ☁️ AWS Services

* AWS IAM
* Amazon S3
* Amazon EC2
* AWS CloudTrail
* Amazon SNS
* Amazon EventBridge
* AWS KMS
* Amazon DynamoDB
* Amazon Bedrock
